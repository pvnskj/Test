# Venkata Parimi — STPO Portfolio Redesign Sandbox

Experimental redesign of the Senior Technical Product Owner portfolio.

## Purpose

This repository is the safe redesign environment. The current portfolio remains in pvnskj/Portfolio and was backed up before redesign work.

The prototype focuses on:
- low-text, high-information case studies
- explicit STPO signals: product goal, prioritization, architecture, dependencies, delivery and evidence
- Jira-inspired decision boards rather than task screenshots
- Vercel/Geist-style grid and typography
- native view transitions
- a lightweight Three.js system visualization
- accessible reduced-motion behavior

See DESIGN_NOTES.md for the full research rationale, content rules and page wireframes.
